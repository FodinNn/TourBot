# TourBot — гид по Казани для MAX

Telegram-style бот-гид по Казани для мессенджера MAX: меню из 6 разделов, ответы
по ключевым словам, кнопка «Что рядом со мной?» с сортировкой достопримечательностей
по расстоянию до пользователя.

## Возможности

- **Меню** — приветствие, 6 кнопок-разделов (must-see, культура и религия, современная
  Казань, гастрономия, маршрут на 1 день, с детьми) + кнопка запроса геопозиции.
- **Разделы по номеру или названию** — «1» – «6» или текст раздела (как на кнопке).
- **Ключевые слова** — «кул шариф», «марджани», «набережная», «чак-чак», «маршрут»,
  «с детьми» и т.д. (словарь в `internal/data/places.go`).
- **«Баумана»** — отдельный ответ про главную пешеходную улицу.
- **Геосервис** — по кнопке «Что рядом со мной?» бот запрашивает локацию и возвращает
  список 8 мест, отсортированный по расстоянию (гаверсинус, формат м/км).
- **Кнопка «Назад»** — в каждом разделе возвращается в меню.
- Порядок проверок ввода: меню-команды → точное прощание → цифры → названия разделов →
  «бауман» → ключевые слова → заглушка + меню.

## Архитектура

```
cmd/bot/main.go            — точка входа: токен из окружения, запуск цикла обновлений
internal/bot/bot.go        — long polling, вложение-локация, отправка ответов (+ клавиатуры)
internal/handlers/         — диспетчер ввода (command.go), геосервис (geo.go)
internal/data/             — тексты экскурсии (texts.go), места и ключевые слова (places.go)
```

Контракт обработчика: `Handle(text string) []handlers.Reply` и
`HandleLocation(lat, lon float64) []handlers.Reply` — оба возвращают список сообщений
(иногда два подряд: заглушка + меню), каждый ответ может нести клавиатуру MAX.

## Запуск

1. Получите токен бота в MAX.
2. Создайте `.env` (или экспортируйте переменную):

   ```bash
   BOT_TOKEN=ваш_токен
   ```

3. Запустите:

   ```bash
   go run ./cmd/bot
   ```
